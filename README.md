# wedding-host

婚礼主持人的 AI 工作台 —— 一个 [Codex](https://github.com/openai/codex) Skill。

> 当前版本：v0.2.0

把婚礼主持人的整套工作流固化：问卷 → 客户档案 → 串词 → 三版本流程表 → 音乐管理。

---

## 它能做什么

| 板块 | 功能 |
|---|---|
| **婚礼业务** | 根据新人问卷生成串词、设计流程、生成三版本流程表（基础版 / 彩排简易版 / 最终版）；一份数据、一条命令，自动贴落款并自检 |
| **音乐** | 仪式前核检（防现场放不出来）· 裁剪某一段 · 录系统声音（兜底） |
| **自媒体** | 触发 FU-ip：拍摄脚本、同类 IP 调研、账号分析 |
| **培训** | 学员毕业海报、公众号图文视频 |

---

## 为什么需要它

婚礼主持人普遍对 AI 使用"粗浅、没有形成工作流"。这个 skill 的价值不是"更聪明的 AI"，而是：

1. **把流程固化** —— 不用每次重新想"该怎么让 AI 干活"
2. **把上下文沉淀** —— 客户档案、历史记录、标准环节清单
3. **降低使用门槛** —— 直接说人话，不用学 prompt

---

## 核心设计：流程表三版本

同一个流程，在不同阶段给不同的人看不同版本 —— 这是婚礼主持工作里最容易被忽略的专业细节：

| 版本 | 时机 | 特点 |
|---|---|---|
| **基础版** | 和新人沟通后 | 详细 + BGM 行；未定写「待定」，蓝字显示 |
| **简易版** | 彩排时 | 一行一环节 + BGM，给彩排人员 |
| **最终版** | 彩排后 | 详细 + BGM，吸收现场变动 |

---

## 固定规则（v0.2.0）

1. **必须用原始 Word 模板填内容**，不能从头新建，否则 logo、底色、边框会丢失。
2. **改字不重建 run**，否则红字重点、蓝色 BGM、彩排版三种字号会一起丢。
3. **彩排版 BGM 用固定左制表位 336pt 对齐**（页面坐标约 x=407.2pt），禁止靠数量不定的空格或 Tab。
4. **落款贴正文区底部且不跨页**，生成后自动用 Word 实际分页校准。
5. **交付一律用 Word（`.docx`）**，PDF 只用于内部预览，不参与交付。
6. **生成后必须跑 `scripts/check_flow.py` 自检**，全绿才算完成。

## 安装

### 1. 装 skill

把 `wedding-host` 文件夹复制到：

```
~/.codex/skills/wedding-host
```

重新打开 Codex。

### 2. 装依赖

```bash
# 音乐工具需要 ffmpeg（免费）
# 下载 https://ffmpeg.org/ 解压后把 bin 目录加进 PATH

pip install -r requirements.txt
```

详细说明见 [使用说明.md](使用说明.md)。

## 使用

### 婚礼业务（在 Codex 里直接说）

```
"帮我给这对新人写开场串词。问卷答案在这里：……"
"帮我把流程表做成彩排简易版。"
```

如果要直接跑标准生成器：先用 `templates/客户数据模板.json` 填好本次数据，再运行：

```bash
python scripts/build_flow.py "客户数据.json" --check
```

它会一次生成：**开场白 + 基础版 + 最终版 + 彩排简易版**，并自动跑结构、BGM、分页和落款自检。

### 音乐（命令行）

```bash
# 仪式前核检（最常用）
python scripts/check_music.py "音乐文件夹"

# 裁剪某一段（30 到 120 秒）
python scripts/trim_music.py "歌.mp3" 30 120

# 录系统播放的声音（下载不到时兜底，注意版权）
python scripts/record_music.py -d 30 -o "录的歌.wav"
```

## 目录结构

```
wedding-host/
├── SKILL.md                  主入口
├── 使用说明.md                面向使用者的详细说明
├── references/
│   ├── 问卷.md               婚礼问卷模板（22 题）
│   ├── 开场白生成规则.md      开场白固定结构与写作规则
│   ├── 流程表排版规范.md      模板 1:1 复刻规则
│   └── 模板填充清单.md        三个模板的坑位与填充清单
├── templates/
│   ├── 标准环节清单.md        19 个固定环节
│   ├── 客户档案模板.md        问卷答案的结构化存储
│   ├── 流程表三版本说明.md
│   └── 客户数据模板.json      一对新人一份数据
└── scripts/
    ├── build_flow.py         一条命令生成开场白 + 三版流程表
    ├── check_flow.py         成品结构 / BGM / 分页 / 落款自检
    ├── fill_flow.py          原始模板填充工具
    ├── export_pdf.py         内部预览备用（非交付物）
    ├── check_music.py        仪式前音乐核检
    ├── trim_music.py         音频裁剪
    └── record_music.py       系统声音录制
```

## 注意

- **音乐录制**是下载不到时的兜底手段，商用需自行处理版权
- **不编造新人信息**，不写敏感话题（离异 / 已故 / 生育 / 经济）
- 生成的串词和流程表**必须人工确认后使用**
