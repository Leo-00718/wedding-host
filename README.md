# wedding-host

婚礼主持人的 AI 工作台 —— 一个 [Codex](https://github.com/openai/codex) Skill。

把婚礼主持人的整套工作流固化：问卷 → 客户档案 → 串词 → 三版本流程表 → 音乐管理。

---

## 它能做什么

| 板块 | 功能 |
|---|---|
| **婚礼业务** | 根据新人问卷生成串词、设计流程、生成三版本流程表（基础版 / 彩排简易版 / 最终版） |
| **音乐** | 仪式前核检（防现场放不出来）· 裁剪某一段 · 录系统声音（兜底） |
| **自媒体** | 触发 FU-ip：拍摄脚本、同类 IP 调研、账号分析 |
| **培训** | 学员毕业海报、公众号图文视频 |

---

## 为什么需要它

婚礼主持人普遍对 AI 使用"粗浅、没有形成工作流"。这个 skill 的价值不是"更聪明的 AI"，而是：

1. **把流程固化** —— 不用每次重新想"该怎么让 AI 干活"
2. **把上下文沉淀** —— 客户档案、历史记录、标准环节清单
3. **降低使用门槛** —— 直接说人话，不用学 prompt

---

## 核心设计：流程表三版本

同一个流程，在不同阶段给不同的人看不同版本 —— 这是婚礼主持工作里最容易被忽略的专业细节：

| 版本 | 时机 | 特点 |
|---|---|---|
| **基础版** | 和新人沟通后 | 详细、无 BGM |
| **简易版** | 彩排时 | 一行一环节 + BGM，给彩排人员 |
| **最终版** | 彩排后 | 详细 + BGM，吸收现场变动 |

## 安装

### 1. 装 skill

把 `wedding-host` 文件夹复制到：

```
~/.codex/skills/wedding-host
```

重新打开 Codex。

### 2. 装依赖

```bash
# 音乐工具需要 ffmpeg（免费）
# 下载 https://ffmpeg.org/ 解压后把 bin 目录加进 PATH

pip install yt-dlp soundcard numpy
```

详细说明见 [使用说明.md](使用说明.md)。

---

## 使用

### 婚礼业务（在 Codex 里直接说）

```
"帮我给这对新人写开场串词。问卷答案在这里：……"
"帮我把流程表做成彩排简易版。"
```

### 音乐（命令行）

```bash
# 仪式前核检（最常用）
python scripts/check_music.py "音乐文件夹"

# 裁剪某一段（30 到 120 秒）
python scripts/trim_music.py "歌.mp3" 30 120

# 录系统播放的声音（下载不到时兜底，注意版权）
python scripts/record_music.py -d 30 -o "录的歌.wav"
```
