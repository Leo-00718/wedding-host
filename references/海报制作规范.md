# 海报制作规范（学员欢迎 / 毕业海报）

> 底板：`assets/poster/base.png`（971×1620，压平 PSD）
> 标准输出：**971×1620 PNG**
> 脚本：`scripts/build_poster.py`

---

## 一、核心原则

1. **底板是唯一版式来源** —— 固定区域（Logo、品言·语言艺术、副标题、欢迎、蓝笔触、
   在场即主角、电话：标签、地址、竖排文案）一律不动，只替换可变内容。
2. **中文必须本地字体绘制** —— 姓名、期数、电话、扫码咨询、竖排文案全部用本机字体画，
   禁止让图片模型生成中文。
3. **二维码必须用原图** —— 等比缩放 + 纯白底，不重绘、不美化。
4. **只用 AI 抠图，不用传统算法** —— 见第三节。
5. **客户隐私** —— 照片与成品只存本地，不上传、不提交公开仓库。

## 三、抠图（关键，踩过坑）

**必须用 `rembg`（u2net_human_seg），不要用 OpenCV GrabCut。**
GrabCut 在「浅色衣服 vs 浅色背景」的影棚照上会残留背景、切掉衣服边缘。

**双通道合成**（这一步不能省）：

```
RGB   ← rembg(alpha_matting=True)   前景色估计，边缘不会灰
alpha ← rembg(alpha_matting=False)  再二值化 + 形态学去锯齿 + 高斯羽化 σ=2.2
```

- **只用 alpha_matting 的 alpha**：边缘有锯齿（礼服/肩部明显）
- **只二值化不加羽化**：边缘发硬，失去顺滑感
- **二值化后忘了换 RGB**：边缘会透出**灰黑色描边**（背景灰残留）

## 四、人物定位（自动锚定，无需手工测量）

```
人物底边 y = 蓝笔触 bbox 顶部 + 蓝笔触高度 × 1.0
```

- 蓝笔触由脚本自动检测（HSV 蓝色 + 取最大连通域）
- 人物**右边缘固定在 x=905**（右侧留白），宽度默认 425，等比缩放
- 蓝笔触 bbox `y[1257,1365]`（高 108）→ 底边落点 **y=1365**
- **比例 1.0 = 人物底边压在蓝笔触的下沿**，与母版 `reference.png` 完全一致
- 换底版时该值自动重算，不要硬编码
- ⚠️ 走【纸条流程】时，对齐锚点的是**撕裂线**，人像底边≠1365（人物实际低于锚点约纸条厚度），见第四节五

**⚠️ 这个比例是从母版实测得出的，不要再凭感觉调：**
- 母版人物底边（主体列 x560-860 中位）= `y 1365`
- 蓝笔触底边 = `y 1365` → 比例 = (1365−1257)/108 = **1.000**

**历史教训**：
1. 早期靠人工画红线标注位置 → 现改为脚本自动锚定；
2. 曾误用"红线画在框中间"推出比例 0.5，导致人物偏高 **54px** → 正确值以**母版实测**为准。

## 四点五、撕纸效果（**已定稿** 2026-10-10）

### 数据来源
母版提取的**原版白边** → `assets/poster/tear_strip.png`（440×100 透明 PNG）
内容区 = 非透明列 `x[25,339]`，共 315px；上边缘黑点已去除。

### ★★★ 三条铁律（违反任意一条必出问题）

**① 纸条轮廓 = 人像轮廓**

纸条的 alpha 必须与人像的 alpha 相乘，纸条只在人像轮廓内出现。
不做这一步，就只能在下面两个错误里二选一：

- ❌ 按「人像图片**包围盒**宽（425）」拉满 → 半身照看不出（撕裂线处宽≈肩宽），
  **全身照纸条两侧露出一大截白边**（实测 No.4 左 73px / 右 32px）
- ❌ 裁成「**撕裂线那一行**轮廓宽的矩形」→ 撕裂线以上人像更宽，
  **人像悬在纸条外面**；而且裁切会让撕裂口的波形索引与纸条毛边错位 `x0` 列，
  **撕口处露缝**

**② 定位必须用【撕裂线】，不能用【图块边界】**

```
撕裂线（= 纸条上边缘 = 人像被裁开的那条线）对齐锚点 y=1365
一体图顶部 y = 1365 − 撕裂线在人像内的 y × 缩放比
```

- ❌ 用「一体图图块底部」对齐 1365 → 图块底部 ≠ 人物边缘，人物整体偏高（实测偏 **59px**）

**③ 锚点 = 蓝笔触下沿 = y1365**

```
蓝笔触 bbox y[1257,1365] → 撕裂线 y = 1365（比例 1.0）
```

### 参数
```
① 纸条内容(315px) 横向缩放到 人像宽 425
② 撕裂线均值 tear_local = 人像高 × 0.90
③ 纸条纵向落位 strip_y = tear_local − median(纸条上边缘)
④ 人像缩放到宽 425，右边缘 x = 905
```

### 流程
```
① 抠图 rembg(u2net_human_seg) 双通道（见第三节）
② 人像缩放到宽 425
③ 纸条内容拉满 425，铺到 425×PH 画布
④ 纸条 alpha × 人像 alpha                      ← 铁律①，唯一同时满足两条约束的做法
⑤ 逐列按纸条上边缘裁掉人像底部（撕裂）
⑥ 撕裂线对齐 y=1365，右边缘 x=905 贴版
⑦ 排版：姓名 / 期数 / 电话 / 二维码 / 竖排文案（见第五节）
```

### ⚠️ 出图后必查（用脚本量，别靠肉眼）
- [ ] 撕裂线全局落点 == **1365**
- [ ] **纸条越出人像轮廓的像素 == 0**（铁律①唯一可靠的判据：纸条层 alpha ⊆ 人像 alpha）
- [ ] 撕裂线连续，相邻列无突变（无垂直台阶）
- [ ] 人像每一列都有对应的纸条列（覆盖率 100%）

### 历史踩坑（都别再犯）
| 坑 | 现象 | 原因 |
|---|---|---|
| 锚点用图块底部 | 人物偏高 59px | 图块底部 ≠ 人物边缘 |
| 纸条没拉满 | 人像两端没白边 | 只摆了图块，没拉伸内容 |
| 纸条按包围盒宽 | 全身照纸条两侧悬空白边 | 包围盒 = 最宽处（肩/臂），≠ 撕裂线处轮廓 |
| 纸条裁成轮廓矩形 | 人像悬在纸条外 + 撕口露缝 | 撕裂线以上人像更宽；裁切使波形索引错位 |
| 撕裂线有台阶 | 某处垂直直角 | 未覆盖列用了不同的撕裂线 |


## 五、姓名排版（**已定稿** 2026-10-10）

### 字体
`assets/fonts/瘦金简体.ttf` —— 细体。第1字笔画密度 **16.1%**（母版目标 14.6%，剩余开源字体均 ≥20%）
（**该字体文件未随公开仓库分发**，需本机自行放置）
> ⚠️ **授权待核（未决）**：字体内部名为「宋徽宗瘦金体」，厂商 `www.sjtype.com`（商业字体站）。
> 来源仓库带 MIT LICENSE，但 **MIT 覆盖的是仓库代码，不等于字体文件本身可商用**。
> **印客户海报前必须确认授权。**

### ★ 四条规则
1. **所有字同一字号（同一 em）** —— 不用母版那种"第 2 字放大 1.22 倍"的做法
   （同一字号下各字墨迹大小天然略有差异，这是正常字体行为，不算"不一样大"）
2. **基准字号 S₀ = 127.5**（= 最初 170 × 0.75，2026-10-10 定稿值）
3. **字距 6.5px**；姓名墨迹**左缘 x = 106**，墨迹**顶 y = 790**
4. **右边界自适应** = 人像在姓名高度带 `y[790,960]` 内的最左边缘 − 2px
   N 个字总宽 `N·S₀ + (N−1)·6.5` 超过可用宽度时，整体等比缩小：
   `S = (可用宽度 − (N−1)·6.5) / N`
   → 不管几个字，**永远不会压到人像**

### 定稿实测（4 张样本，2026-10-10）
| 学员 | 名字 | 可用宽 | 字号 | 实际右缘 |
|---|---|---|---|---|
| 1 | 张文（2字） | 512 | 127.5 | 367 |
| 2 | 张暮雨（3字） | 494 | 127.5 | 502 |
| 3 | 汪怡嘉（3字） | 565 | 127.5 | 502 |
| 4 | 欧阳雨欣（4字） | 381 | **90.4（自动缩小）** | 484 |

### ⚠️ 未决
- **授权**（见上）
- **全身照 + 长名字**：人像靠左时可用宽只剩 ~380px，4 字名字被压到 ~90 号（基准的 71%）。
  若要改善，只有三条路：放宽右边界（允许压到人像）／设最小字号／长名字换行。**暂按现状**

### 调参入口
`build_poster.py` 支持 `--name-size` / `--name-gap` / `--name-x`，改数值不用改代码。

### 历史做法（已废弃，别再回退）
逐字字体混排（吕建德行楷 / LongCang×0.75 / 志莽行书×0.78），字高145、x=128、y=778、间距44。
废弃原因：① 吕建德行楷把简体码位映射成**繁体字形**（张→張、赵→趙）；② 笔画比母版粗一倍以上；③ 3 字以上撞人像。


## 五点五、期数排版（**已定稿** 2026-10-10）

### 字体
**系统等线** `C:\Windows\Fonts\Deng.ttf`（Windows 8+ 自带）——**不需要随仓库分发字体文件**，
所以不引入新的授权问题，也不影响换机可移植性。

选它的依据（同一窗口实测，母版目标 宽165 高26 密度24.8%）：

|---|---|---|---|---|
| **母版（目标）** | 165 / 26 | [25,12,12,25,25,24] | [26,22,21,26,26,26] | 24.8% |
| **等线 Deng ✅** | 163 / 26 | [25,12,12,25,24,23] | [26,19,19,26,26,25] | **24.8%** |
| 宋体 simsun | 164 / 26 | [24,10,10,24,24,22] | [26,19,19,26,26,26] | 19.6% |
| 思源宋 450 | 171 / 26 | [26,12,12,26,26,24] | [25,21,21,25,25,24] | 25.1% |

### ★ 排版规则
1. **字号 28、字距 5**
2. **左缘 x = 131、顶 y = 978**（成品实测左缘落在 132，与母版一致）
3. **逐字绘制**（不是整串一次性画），字间距固定 5px
4. **汉字按【底线】对齐；数字/拉丁字母【单独排版】——在行内垂直居中**
   依据母版实测：汉字 y[978,1003]，数字 y[980,1001]（居中）。
   ⚠️ **不要让数字与汉字底边齐平**：数字矮，齐平后视觉上会"沉下去"，整行底线看起来是弯的。
5. 上下微调：`--qi-num-dy`（正数=数字下移）

## 五点六、二维码 / 电话 / 扫码咨询（**已定稿** 2026-10-10）

三个元素全部照母版实测「原子级对齐」，不缩放、不重绘、不美化。

| 元素 | 母版实测 | 定稿参数 |
|---|---|---|
| **二维码** | x[88,179] y[1422,1513] **92×92** | `qr_x=88  qr_y=1422  qr_size=92`，等比贴入、自动去白边 |
| **扫码咨询** | x[104,158] y[1530,1542] **55×13** | `saoma_y=1530  saoma_size=14`（宋体），水平居中于二维码下方 |
| **电话** | 数字宽9 高15 **间距11**，左缘301 顶1485 | `phone_x=301  phone_y=1485  phone_size=22`（宋体） |

**电话为什么是宋体 22 号**：母版数字间距 11px，而宋体半角数字的字宽步进 = 字号 ÷ 2，
22 ÷ 2 = **11**，与母版**完全吻合**（9×15 的墨迹尺寸也对得上）。
号码建议按 **3-4-4 用空格分组**（母版就是这样，空格正好占一个数字宽）。

**成品实测**：二维码与母版**逐像素同位置同尺寸**；扫码咨询宽高一致（位置差 2px）；电话左缘差 2px。

## 五点七、批量出图：一张学员海报 × N 个老师（**已定稿** 2026-10-10）

### 场景
同一张学员海报，由 **9 位老师**各自发朋友圈 → 需要 **9 份不同的二维码 + 电话号码**，
其它一切（人像、撕纸、姓名、期数）**完全相同**。

### 老师清单（CSV，Excel 直接编辑）
3 列：`老师`、`二维码`、`电话`；**可带表头**；Excel 另存为 CSV（UTF-8 或 GBK 都兼容）。

```csv
老师,二维码,电话
王老师,D:\二维码\王老师.png,138 0000 0001
李老师,D:\二维码\李老师.png,138 0000 0002
（共 9 行）
```

### 一条命令出 9 张
```powershell
python scripts/build_poster_batch.py 学员照.jpg --name "张文" --cohort "第34期学员" ^
    --teachers "老师清单.csv" --outdir "出图"
```

- 输出：`{学员姓名}-{老师}.png`，**每个老师一张，二维码与电话一一对应**
- **人物抠图只做一次**（N 张共享），所以批量比逐张快得多（9 张约 6 秒）
- 某行二维码文件不存在 → 该行**跳过并明确提示**，其余照常出图

### ★ 固定话术（对 Codex 说这句即可）
```
用 wedding-host 给 <学员姓名>（<期数>）出海报。
照片：<照片路径>
老师清单：<CSV 路径>
```
如果懒得做 CSV，也可以直接把 9 位老师按 `老师 | 二维码路径 | 电话` 一行一位贴给我，我来生成清单。
