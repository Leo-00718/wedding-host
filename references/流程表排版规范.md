# 流程表排版规范（1:1 复刻标准）

> 来源：张暮雨提供的 3 份原始模板（仪式流程表 / 彩排 / 最终版）

## ⚠️ 最核心的规则：绝不要从头新建，必须用「原始 Word 模板填内容」

**生成流程表的唯一正确方式 = 用原始 `.docx` 模板，替换文本内容。**

- 模板位置（张暮雨电脑）：三个原始 docx 文件
- 工具：`scripts/fill_flow.py`
- 用法：`python fill_flow.py <模板.docx> <输出.docx> <替换配置.json>`

**为什么不能从头新建：**
- 模板里有 logo、底纹、表格底色、边框等设计元素
- 这些是图片和矢量对象，python-docx 新建时无法复刻
- 只有"打开模板→替换文字→另存"，才能 100% 保留设计

**替换内容（每场婚礼都要换的）：**
- 新人姓名（注意格式"新 郎 & 新 娘"，姓和名之间有空格）
- 仪式时间、婚礼酒店、桌数
- 仪式人员、新人准备、工作人员准备
- 概要、环节音乐、婚礼基调、座位安排
- 各环节的具体描述 + BGM

**模板里有 3 张内嵌图片，必须原样保留，不得删除。**

## 一、总原则

1. **全篇字体 = 楷体（KaiTi）**
2. 字号用**标准中文字号**（见下表）
3. 标题、章节头、正文、表格的结构位置必须与模板一致

## 二、字号对照表

| 用途 | 中文字号 | 磅值 |
|---|---|---|
| 大标题「Wedding 婚礼流程」 | 小三 | **15pt** |
| 章节头（框架摘要 / 仪式流程细则 / 一、婚礼仪式流程） | 三号 | **16pt** |
| 正文 / 表格内容 | 五号 | **10.5pt** |
| 彩排简易版·环节名（1、控场+灯光秀） | 小二 | **18pt** |
| 彩排简易版·日期/基调/结尾/署名 | 四号 | **14pt** |
| 彩排简易版·括号动作 / BGM | 小四 | **12pt** |
| 联系电话 | 五号 | **10.5pt** |

**要点：**

## 八、落款必须「贴页底」

落款 = `logo + 主持人联系电话 + 工作室署名`，共 3 行，是一个整体。

**规则：**
1. 落款要**贴住正文区的底部**，不是紧跟表格
2. 整块**不能跨页**、不能被挤到新的一页
3. 位置标准：**在落款前再加一个空行，落款就会翻页** —— 这就是要的「极限」位置

**实现：** `scripts/fill_flow.py` 里的 `_place_signature_at_bottom()` 自动完成 ——
生成好 docx 后用 Word 打开，一行一行加空行，直到落款不再和正文同页，再撤回最后一行。
每场内容长短不同，它都会自动算到极限，不用手工数空行。

**依赖：** 本机要装 Microsoft Word + `pywin32`（`pip install pywin32`）。
没装会打印警告并跳过，落款就退回模板原样（紧跟表格）。

⚠️ **这个位置是零容差的。** 用 WPS、LibreOffice 等非 Word 软件打开，可能被挤到多出来的一页。
★ **交付格式固定为 Word（`.docx`），不导 PDF** —— 所有成品一律交 docx。
