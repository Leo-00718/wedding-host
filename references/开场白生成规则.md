# 开场白生成规则

> 来源：张暮雨提供的《各有各路》开场白范例集（90 篇，已全文 OCR 提炼）
> 这是本 skill 生成所有开场白的唯一风格标准。

---

## 一、核心心法（书名就是答案）

**「各有各路」= 每一场婚礼的开场白，都要找到一条独属于这对新人的切入路线。**

**永远不要用"今天是个好日子""欢迎来到现场"这种万能套话开场。**

---

## 二、核心结构（5 段式）

```
① 问候 + 欢迎（1~2 句）
② 切入物展开（讲一段普遍、有画面感的话）
③ 过渡到新人（把②落到这对新人的真实故事）
④ 金句点题（一句话收束，对仗/排比）
⑤ 欢迎入场（1~2 句）
```

---

## 三、切入角度库（9 大类，从 90 篇提炼）

**选一个角度作为全文支点，全文围绕它展开。**

### 1. 物象切入（最常用）
用"一个具体物件/自然意象"做全文隐喻。
- 范例标题：一树花开、玫瑰、森林、水晶、蓝色、红色、沙漠、风、雨天、咖啡、黑白、光、人生果实
- 方法：找一个意象 → 讲它的普遍含义 → 映射到新人爱情

### 2. 场地/地点切入
用"婚礼场地或新人城市"开场。
- 范例：二六市（查地名由来）、舟山归来不看岛、离海有多近、湖畔草地、归途、远近、南北
- 方法：从场地特征/地名典故切入，引出"相聚"

### 3. 时间切入
用"时间"这个母题。
- 范例：时间节点一站一换、万能时间开场、时间来信（时间给新人写信）、时间的答案、时光地图、时光毕业礼
- 方法：串联新人的关键时间节点，或让"时间"拟人化

### 4. 节日/节气切入
用"婚礼当天的节日/节气"。
- 范例：劳动节、惊蛰（燕子还巢）、立夏
- 方法：从节日的意义切入，落到"今天也是你们人生的节日"

### 5. 概念/观点切入
用"一个流行概念或观点"立论。
- 范例：奢侈品、情绪价值、爱之不易得、松弛感、期待便是幸福本身、只道寻常、真实简单、复杂与简单、比较级、Plan B、心安
- 方法：先定义/论述一个概念，再用新人的故事来印证

### 6. 人物/关系切入
用"某个人物"开场。
- 范例：妈妈是谁、牵手、回家、相遇
- 方法：从一个具体的人（往往是父母）切入

### 7. 影视/IP/文学切入
借"一部作品"。
- 范例：剧院（哆啦A梦）、Neverland、骑士、光的颜色
- 方法：借影视情节/文学意象，映射到新人故事

### 8. 职业切入
用"新人的职业"。
- 范例：一树花开（人民教师）
- 方法：从职业特征/意义切入，过渡到"对爱情也一样认真"

### 9. 特殊形式
打破常规结构。
- 范例：时间来信（全文以"时间"为第一人称写信）、新郎登台后致辞
- 方法：变换叙事人称/视角

## 四、最关键的一招：从问卷里挖「具体物件」

**这是《各有各路》最值钱的技术。**

好开场白里总有一个"具体的、有画面的小物件/小细节"，作为情感支点：

| 范例 | 支点物件 |
|---|---|
| 爱是细水长流 | 一张**创可贴**（第一次约会划伤手，男生默默递上） |
| 奢侈品 | 每年生日的**口红**（分手期间偷偷以朋友名义送） |
| 剧院 | 一组**哆啦A梦同款婚纱照** |
| 劳动节 | 两位妈妈头发里的**白发** |
| 启程和开始 | 一次**密室逃脱**的相遇 |

**规则：写开场白前，先问自己——问卷里有没有一个"能代表他们爱情的具体物件"？有，就让它当全文的钩子。**

## 五、语言风格要求

1. **短句为主**，口语化但有书面美
2. **大量意象和比喻**，避免直白陈述
3. **金句要有对仗/排比**，能让人记住
4. **温暖、有力量，但不煽情、不矫情**
5. **每篇一个"文眼"**（一句点题的话，通常就是标题）

**金句范例（从原书提取）：**
- "心动是相遇，心安是相守"
- "在婚姻里，没有人是老师，所有人都是学生"
- "爱情，是这世上最大的奢侈品"
- "时间，是所有情感的试金石"

---

## 六、生成流程（从问卷到开场白）

```
第 1 步：读客户档案，抓出 3 个关键素材
        · 一个「具体物件/细节」（优先）
        · 一个「恋爱故事节点」
        · 一个「性格/职业特点」

第 2 步：选切入角度
        · 优先从素材本身找（有职业用职业，有物件用物件，有节气用节气）
        · 没有明显素材 → 用「时间」或「概念」这类万能但不算套话的角度

第 3 步：按 5 段式写

第 4 步：检查金句有没有，没有就提炼一句
```

---

## 七、红线（必须遵守）

1. **所有细节必须来自问卷**，不得编造
2. **避开问卷标注的敏感话题**（离异/已故/生育/经济/家庭矛盾）
3. **标注"不要在现场说"的内容**，绝对不用
4. **不煽情**——除非新人明确要求煽情风格
5. **基调要跟客户档案一致**（自然轻松/温暖走心/热闹欢乐/庄重简洁）
