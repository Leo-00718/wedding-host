# 标准环节清单（婚礼仪式）

> 从张暮雨的真实流程表（3 个 PDF）提炼。
> 这是"基础流程"，具体每场婚礼按问卷结果增删改。

## 固定环节（按顺序）

| # | 环节 | 要点（从真实模板提炼） |
|---|---|---|
| 0 | 仪式前 | 温馨提示来宾入座、灯光秀 |
| 1 | 开场 | 主持人开场白 |
| 2 | 新郎入场 | 从舞台右侧入场，拿手捧花；走到主舞台转身与来宾挥手/鞠躬 |
| 3 | 新郎候场 | 走到 T 台末端，转身面对舞台等候 |
| 4 | 新娘入场 | 独立入场；伴郎伴娘在厅内两侧维持秩序；音乐响新娘默数两个数后缓缓走进；注意台阶、表情、微笑；走到 T 台末端拍拍新郎肩膀 |
| 5 | 共同入场 | 新郎站新娘右侧，上主舞台面对来宾 |
| 6 | 誓言 | 问答方式、民法典版本 |
| 7 | 交换戒指 | 手摘星辰方式（新郎向空中摘星） |
| 8 | 拥抱 | 新人拥抱，新娘脸朝来宾 |
| 9 | 父母入场 | 从 T 台末端入场；2 位妈妈前牵手、2 位爸爸后，2×2 队形；妈妈挨着新人站 |
| 10 | 家庭合影 | 全家福合影 |
| 11 | 共同举杯 | 伴郎托盘送 6 杯高脚杯，杯口与眼平齐 |
| 12 | 手捧花 | 送给 2 位妈妈（伴娘递送） |
| 13 | 大合影 | 新人走到第二桌位置转身；4 位伴郎伴娘在后；先照片后视频；暗场 |
| 14 | 红包分享 | T 台末端撒红包（最安全处）；少量多次；统筹师端托盘；伴郎伴娘围人墙维护秩序 |
| 15 | 礼成退场 | 挥手致谢退场换装；伴郎伴娘鼓掌欢呼 |
| 16 | 换敬酒服 | 15-20 分钟 |
| 17 | 返场敬酒 | 统筹师备酒杯；一桌一桌敬酒；主持人语言引导 |
| 18 | 温馨提示 | 至少提示 2 遍：晚宴时间、地点、棋牌娱乐、停车票、禁烟 |

## 可加环节（按新人情况）

- 改口敬茶（默认不在舞台上喝）
- 新人誓言朗读（替代问答式）
- 惊喜环节（求婚回顾、亲友祝福视频等）

## 框架摘要字段（每场必填）

| 字段 | 说明 |
|---|---|
| 新人姓名 | 例：王渝 & 杨兴渝 |
| 仪式时间 | 例：12:08 |
| 婚礼酒店 | 例：宝铂丽国际宴会艺术中心（礼嘉店）- 绯色炽恋 |
| 桌数 | 例：20-24 桌 |
| 仪式人员 | 新郎、新娘、双方父母、伴郎伴娘几对 |
| 新人准备 | 例：拇指灯、红包 100 个 |
| 工作人员准备 | 例：麦克风 2 支、高脚杯 6 支、手捧花 2 束 |
| 概要 | 特别说明，如"不在舞台上喝改口茶" |
| 环节音乐 | 新人确定后发给主持人 |
| 婚礼基调 | 例：不煽情、轻松自然 |
| 座位安排 | 例：T 台两侧安排年轻朋友 |
