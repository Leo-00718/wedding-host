# 流程表 · 三版本说明

> 同一个流程，在不同阶段给不同的人看不同版本。
> 这是张暮雨工作流里最关键的细节。

## 版本 1：基础版（沟通拟定版）

- **用途**：和新人第一次沟通后，发给新人确认
- **特点**：详细、**无 BGM**（音乐还没定）
- **包含**：框架摘要 + 完整环节描述 + 温馨提示

## 版本 2：简易版（彩排版）

- **用途**：彩排时给彩排人员、统筹师、督导看
- **特点**：**一行一环节 + BGM**，只保留执行要点
- **包含**：环节编号 + 环节名 + 关键动作 + BGM + 双方准备清单

## 版本 3：最终版（执行版）

- **用途**：现场正式仪式用（主持人自己 + 关键人员）
- **特点**：**详细 + BGM**，吸收彩排后的现场变动
- **包含**：框架摘要 + 完整环节描述 + BGM + 温馨提示

## 生成规则（Skill 要遵循）

1. **先有基础版**，再往下派生
2. 每次只做"当前阶段需要的那一版"，不要一次性生成全部
3. **彩排后的变动**要回写到最终版，并标注"（彩排后修改）"
4. 所有版本**底部都要带**：主持人联系电话 + 工作室署名 + 祝福语
